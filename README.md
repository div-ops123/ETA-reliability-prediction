Business problem

Delivery platforms need reliable delivery-time estimates to manage customer expectations. Underestimation creates late-delivery surprises, while excessive overestimation can discourage orders.

ML problem
Predict the end-to-end delivery duration, in seconds, using information available at order submission.

Buiness objective:
Improve the reliability of delivery time estimates without unnecessarily inflating the time communicated to customers.

V0:
an offline ETA reliability prototype using DoorDash historical delivery data from Kaggle.
